1. Performance

Python execution bottlenecks on large benchmarks. editex takes 831 µs per call in Python vs 26 µs natively in Rust — a 31× speedup.

2. Memory Safety

Python/C byte slicing risks UTF-8 boundary panics on CJK, Emojis, and multi-byte token vectors. Rust eliminates this entirely.

3. Type Safety

Rust's generic &[T] slices enforce correctness at compile time — no silent zero-division or tuple unpacking bugs like Python's MongeElkan upstream issue.

  • 🛡️ Zero Unsafe Code: #![forbid(unsafe_code)] enforced at compile time — no unsafe blocks, no raw pointers.
  • 🧩 Generic Sequences &[T]: Algorithms operate over &[char] / Vec<&str> token slices. Prevents UTF-8 panics.
  • ⚙️ Dual Trait System: DistanceMetric<T> and SimilarityMetric<T> auto-derive 4 metrics from 1 implementation.
  • 🔄 Persistent JSON-IPC CLI: textdistancerust-cli streams JSON over stdin/stdout for high-volume differential fuzzing.
  • 🎨 Interactive CUI (tdcli): Native terminal UI with box-drawing tables, emoji category tags, and visual bars.
  • 🐳 Docker Containerized: Single multi-toolchain image with Rust 1.82 + Python 3.11 — ready for CI/CD.

60 unit tests verify individual algorithm edge cases. 29 known-value integration tests assert exact results to 10-7 tolerance for all 30 algorithms.

3. Docker + CI
